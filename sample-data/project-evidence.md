# Campus Room Booker contribution report

Fictional project evidence for testing. Project period: January 2026 to April 2026. Team: three students. This report attributes work to fictional candidate Mira Rao.

## Mira's interface contribution

Mira built the room-availability view and booking-form screens using React and TypeScript. She implemented client-side form validation, loading indicators and inline error messages. A different teammate implemented the backend service.

## API integration

Mira connected these screens to the team's existing REST endpoints for listing rooms and creating booking requests. She handled unsuccessful API responses in the interface. She did not design or implement the backend API.

## Automated tests

Mira authored 18 Vitest unit tests for the booking form's validation and error states. The project report does not measure code-coverage percentage or claim all tests passed across every environment.

## Accessibility work

Mira added visible keyboard focus states, associated input labels and accessible inline error text to the booking form. She manually checked the keyboard flow. The project did not receive an accessibility certification or a formal WCAG compliance audit.

## Collaboration

Mira used Git branches and pull requests to submit her changes. The three students shared project work; Mira was not designated the team leader. The project is a student prototype rather than a commercial deployment.
